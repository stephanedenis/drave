# BPE (Byte Pair Encoding ; codage par paires d'octets)

> **Fiche glossaire — BPE (Byte Pair Encoding ; codage par paires d'octets).** Algorithme de tokenisation qui découpe le texte en morceaux fréquents, appris statistiquement. Le moteur en a une implémentation Rust conforme au pré-tokenizer Qwen2 (737 cas sur 737) ; le `src/bpe_np.py` du harnais, lui, s'en écarte sur 5 points (5,2 % des identifiants) (`reports/rapport-inference.md:157-168`).
