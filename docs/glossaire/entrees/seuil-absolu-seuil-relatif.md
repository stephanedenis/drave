# Seuil absolu · seuil relatif

> **Fiche glossaire — Seuil absolu · seuil relatif.** Un seuil *absolu* coupe les activations sous une valeur fixe ; un seuil *relatif* les coupe sous une fraction du maximum du vecteur. Mesure : le seuil absolu est **10× moins efficace** que le k-WTA à sparsité égale (`reports/rapport-parcimonie-imposee.md:47`, `docs/roadmap.md:139-141`).
