# Profondeur de sonde · fenêtre · taux de récupération

> **Fiche glossaire — Profondeur de sonde · fenêtre · taux de récupération.** Vocabulaire du test de l'aiguille : le code à retrouver est planté à une *profondeur* relative (0,1 = tout au début, 0,9 = tout à la fin), chaque essai est une *sonde*, et le *taux de récupération* est la fraction de sondes réussies.
