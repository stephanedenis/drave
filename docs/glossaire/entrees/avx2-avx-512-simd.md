# AVX2 · AVX-512 · SIMD

> **Fiche glossaire — AVX2 · AVX-512 · SIMD.** *SIMD* : une instruction qui traite plusieurs nombres à la fois. *AVX2* est le jeu d'instructions 256 bits des processeurs x86 Haswell du banc ; le noyau de tête `Q8_0` l'utilise (`vpmaddwd` sur 32 niveaux), et la somme entière est exacte **au bit près** (`docs/contexte-long.md:378-382`).
