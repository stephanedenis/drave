# Encodage positionnel rotationnel

> **Fiche glossaire — Encodage positionnel rotationnel.** La façon dont un modèle transformer inscrit la **position** d'un jeton dans son vecteur. Elle a une conséquence méthodologique : la position est lisible dans la couche 0, donc une lecture pourrait prédire le contenu par la seule position **si le corpus est aligné**.
