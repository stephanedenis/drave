# Nibble (quartet)

> **Fiche glossaire — Nibble (quartet).** Un demi-octet, soit 4 bits. Un poids 4 bits est un nibble ; deux poids tiennent donc dans un octet, l'un dans les bits bas, l'autre dans les bits hauts (`docs/convertisseur.md:26-33`).
