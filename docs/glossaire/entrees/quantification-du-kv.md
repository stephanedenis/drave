# Quantification du KV

> **Fiche glossaire — Quantification du KV.** Quantifier les clés et les valeurs du cache plutôt que les poids. Résultat central : **tout l'écart vient des clés**, parce qu'une erreur de clé entre dans le softmax et déplace le poids relatif d'une position entière, alors qu'une erreur de valeur se moyenne (`docs/roadmap.md:155-194`).
