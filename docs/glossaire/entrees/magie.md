# Magie (nombre magique)

> **Fiche glossaire — Magie (nombre magique).** Constante en tête de fichier ou de message qui permet de reconnaître le format : `0x44525631`, soit les octets `DRV1`, pour le protocole de flux. Une magie absente signale une désynchronisation du flux d'octets (`docs/format-flux.md:92`).
