# Nœud moteur · pilote · pair

> **Fiche glossaire — Nœud moteur · pilote · pair.** Dans la démonstration répartie, le **pilote** garde les N premières couches (`--ppl-reparti <hôte:port> --couches-locales N`) et le **nœud moteur** sert le reste (`--flux-serveur <port>`) ; le *pair* est l'homologue vu par le protocole. Les deux nœuds doivent charger le **même GGUF** : la dimension ne voyage pas (`docs/colab-reparti.md:70-102`, `docs/format-flux.md:126-129`).
