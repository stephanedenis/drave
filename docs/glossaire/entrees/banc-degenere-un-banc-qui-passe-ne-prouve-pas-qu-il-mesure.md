# Banc dégénéré · « un banc qui passe ne prouve pas qu'il mesure »

> **Fiche glossaire — Banc dégénéré · « un banc qui passe ne prouve pas qu'il mesure ».** Un banc dont les données rendent le résultat vrai pour de mauvaises raisons. Exemple consigné : un banc de scores GPU où toutes les positions partageaient la même clé, ce qui a donné 1,03e-7 au lieu de 1,60-2,25e-7 (`reports/rapport-gpu-scores.md:27-36`, `docs/sprints.md:69-73`).
