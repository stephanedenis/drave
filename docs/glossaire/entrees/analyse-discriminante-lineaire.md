# Analyse discriminante linéaire

> **Fiche glossaire — Analyse discriminante linéaire.** Trouver les directions d'un espace qui **maximisent le rapport** entre la variance d'un groupe et celle d'un autre. C'est un **problème aux valeurs propres généralisé**, `C_cont·v = λ·C_lang·v`, donc **en forme fermée** et sans rétropropagation.
