# Porte (de décision)

> **Fiche glossaire — Porte (de décision).** Un chiffre, mesuré sur cette machine, qui décide de continuer ou d'abandonner une branche ; « une porte non franchie arrête la branche — pas de poursuite par inertie » (`docs/programme-recherche.md:134-135`, `:210`). Exemples : *Porte A* (une variante bat le modèle de base de ≥1 % de perplexité), *Porte C* (apprendre un fait à l'inférence sans oubli catastrophique).
