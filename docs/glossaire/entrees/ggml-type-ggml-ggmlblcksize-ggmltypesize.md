# ggml · type ggml · ggmlblcksize · ggmltypesize

> **Fiche glossaire — ggml · type ggml · ggmlblcksize · ggmltypesize.** Ggml est la bibliothèque de tenseurs qui sous-tend llama.cpp, et donc la définition de référence des types quantifiés. Chaque type déclare combien de poids tient dans un bloc (`ggml_blck_size`) et combien d'octets pèse ce bloc (`ggml_type_size`) : un `Q4_K` range 256 poids en 144 octets.
