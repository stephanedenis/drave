# Version (du format et du protocole)

> **Fiche glossaire — Version (du format et du protocole).** Trois numérotations coexistent et il faut les distinguer : la **trace** est en version 1/2/3 (`DRAVE_TRACE_BLOCS`), le **protocole réseau** en version 5, et le fichier GGUF a sa propre version d'en-tête. Un refus de version est prononcé **avant** toute interprétation du corps (`docs/format-flux.md:20-24`, `:143-153`).
