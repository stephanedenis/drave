# Principe de maître

> **Fiche glossaire — Principe de maître.** Une **règle courte** tirée d'un ouvrage du domaine public (Lasker, Capablanca, Nimzowitsch, Tarrasch, Payne, Smith, Cavendish, les proverbes du go) et **encodée** dans la pensée : évaluation, livre d'ouvertures, prior de MCTS ou politique. Un principe n'est pas une citation : c'est une règle mesurable, avec son **contrôle** (la même recherche sans le principe).
