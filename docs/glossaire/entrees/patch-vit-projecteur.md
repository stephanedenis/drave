# Patch · ViT · projecteur (mmproj)

> **Fiche glossaire — Patch · ViT · projecteur (mmproj).** Un *patch* est un carré d'image (14 × 14 pixels) traité comme un jeton ; le *ViT* est la tour de vision qui les encode ; le *projecteur* (`mmproj`) traduit ces vecteurs vers la dimension du modèle de texte. Chaîne démontrée de l'image aux logits sur Qwen2.5-VL-7B (`docs/plan-mla-vision.md:654-671`).
