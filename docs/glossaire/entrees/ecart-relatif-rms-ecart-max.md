# Écart relatif · RMS · écart max

> **Fiche glossaire — Écart relatif · RMS · écart max.** Façons de chiffrer une erreur. L'*écart max relatif* est utilisé pour comparer des tenseurs (1e-7, 5,2e-7, 1,8e-6) ; le *RMS* (root mean square) pour une erreur répartie (0,085 % du max de la liste pour la trace v3) ; la *tolérance* du dépôt pour un noyau GPU est 1e-6 (`docs/format-flux.md:62-65`, `reports/rapport-gpu-scores.md:50-52`).
