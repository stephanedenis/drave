# SiLU · SwiGLU

> **Fiche glossaire — SiLU · SwiGLU.** *SiLU* est une non-linéarité lisse (`x·σ(x)`), aussi appelée sigmoid linear unit. *SwiGLU* est le bloc FFN qui combine deux projections avec cette porte : `a = SiLU(u·x) · (v·x)`, puis `a·d` (`reports/rapport-greffon.md:12-15`).
