# Valeur propre

> **Fiche glossaire — Valeur propre.** Pour une matrice `M`, un vecteur `v` tel que `M·v = λ·v` : la matrice ne fait que l'étirer, sans changer sa direction. Le nombre `λ` est la valeur propre associée.
