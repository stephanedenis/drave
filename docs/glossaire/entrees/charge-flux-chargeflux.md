# Charge · Flux · ChargeFlux

> **Fiche glossaire — Charge · Flux · ChargeFlux.** Structures internes du protocole : `ChargeFlux::Dense(Vec<f32>)` porte un vecteur, `ChargeFlux::Liste(...)` une liste quantifiée, `ChargeFlux::Lot(Vec<f32>)` un lot d'états aplati. `plat()` rend le vecteur plat d'un lot ; `en_dense()` panique nommément sur un lot, pour qu'on n'appelle pas la mauvaise conversion (`drave-core/src/main.rs`, `docs/plan-prefill-reparti.md:116-126`).
