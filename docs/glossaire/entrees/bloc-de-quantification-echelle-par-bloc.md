# Bloc de quantification · échelle par bloc

> **Fiche glossaire — Bloc de quantification · échelle par bloc.** Les poids quantifiés sont rangés par paquets (blocs) de 32 ou 256, chacun accompagné d'une **échelle** (un facteur multiplicatif) qui ramène les entiers dans la dynamique réelle. « Ce n'est pas le nombre de bits qui compte, c'est la finesse des échelles » : passer d'une échelle par vecteur à une échelle par bloc de 32 fait tomber le coût…
