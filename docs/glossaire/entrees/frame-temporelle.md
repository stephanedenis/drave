# Frame temporelle

> **Fiche glossaire — Frame temporelle.** Dans un simulateur à impulsions, la tranche de temps pendant laquelle on regroupe les événements avant de les traiter. Le projet `neuronspikes` annonce des frames jusqu'à 15 360 Hz, soit une résolution de 65 microsecondes.
