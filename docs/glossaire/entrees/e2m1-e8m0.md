# E2M1 · E8M0

> **Fiche glossaire — E2M1 · E8M0.** Les deux composants du format MXFP4 : **E2M1** est la valeur sur 4 bits (1 bit de signe, 2 d'exposant, 1 de mantisse, soit les huit magnitudes {0, ½, 1, 1½, 2, 3, 4, 6}) ; **E8M0** est l'échelle de bloc sur 1 octet, une puissance de deux. Tous deux lus dans le fichier gpt-oss sans requantification (`reports/rapport-passage-a-l-echelle.md:77-79`).
