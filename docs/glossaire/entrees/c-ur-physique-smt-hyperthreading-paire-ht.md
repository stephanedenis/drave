# Cœur physique · SMT · hyperthreading · paire HT

> **Fiche glossaire — Cœur physique · SMT · hyperthreading · paire HT.** Un cœur *physique* exécute un flux ; le *SMT* (hyperthreading) fait apparaître deux fils logiques par cœur en partageant certaines ressources.
