# Plafond (PLAFONDFLUX, verifiertaille)

> **Fiche glossaire — Plafond (PLAFONDFLUX, verifiertaille).** Garde-fou de sûreté : toute taille annoncée par un message est vérifiée **avant** l'allocation correspondante, contre un plafond de 256 Mo ; un cumul est vérifié état par état. Sans lui, un en-tête corrompu provoquerait un épuisement mémoire au lieu d'une erreur de protocole (`docs/plan-mode4-lot-listes.md:183-232`).
