# Débit · latence · aller-retour · TTFT

> **Fiche glossaire — Débit · latence · aller-retour · TTFT.** Le *débit* est ce qui passe par seconde (Go/s, tok/s, événements/s) ; la *latence* est le délai d'un aller-retour. Leçon du transport réparti : « le débit ne compte pas (0,25 Mbit/s), la latence compte quatre fois » — `attente ≈ calcul distant + 3,2 × latence` (`docs/roadmap.md:57`).
