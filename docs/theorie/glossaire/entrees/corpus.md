# Corpus

> **Fiche glossaire — Corpus.** Un **ensemble de textes** réuni pour une mesure, avec son mode d'emploi : d'où il vient, ce qu'on a retiré, comment il est découpé. Dans le dépôt, un corpus n'existe pas sans son **manifeste** (`reports/corpus-*.json`) : nombre d'articles ou de documents, caractères, octets par split, empreintes SHA-256.
