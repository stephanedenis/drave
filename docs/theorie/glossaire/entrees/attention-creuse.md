# Attention creuse

> **Fiche glossaire — Attention creuse.** Attention restreinte aux k meilleures clés par requête (`--attn-topk`) ou à une fenêtre (`--attn-window`). Mesure contre-intuitive du dépôt : restreindre aux 256 meilleures clés **améliore** la perplexité de 21 % sur du texte brut, parce que l'attention lointaine ajoute du bruit (`docs/implantation/contexte-long.md:557-578`).
