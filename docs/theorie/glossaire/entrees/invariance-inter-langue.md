# Invariance inter-langue

> **TL;DR — Invariance inter-langue.** À quel point deux langues qui disent la même chose ont des représentations qui se ressemblent. Mesurée par la similarité de cosinus entre les représentations de langues différentes pour un même contenu aligné, moyennée sur toutes les paires.
