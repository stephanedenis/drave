# Tronçon

> **Fiche glossaire — Tronçon.** Un **morceau de texte** de taille fixe (8 192 caractères par défaut), coupé de préférence à un espace pour ne pas casser un mot. Le corpus est écrit en tronçons séparés par une ligne vide ; la déduplication se fait au tronçon pour le train.
