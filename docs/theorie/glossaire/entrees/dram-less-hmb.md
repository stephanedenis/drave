# DRAM-less · HMB (Host Memory Buffer)

> **Fiche glossaire — DRAM-less · HMB (Host Memory Buffer).** Un SSD *DRAM-less* n'a pas de cache interne et emprunte un peu de RAM hôte (*HMB*) pour ses tables ; le NVMe de la machine est un MAP1602 de ce type, ce qui explique une partie de ses performances en lecture aléatoire (`reports/rapport-architecture-memoire.md:221`, `:285`).
