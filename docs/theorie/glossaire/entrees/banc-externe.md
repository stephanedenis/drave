# Banc externe

> **TL;DR — Banc externe.** Le dispositif qui sort le **langage** des GPU : **DeepSeek** (API) pour traduire, juger, générer et évaluer ; les GPU et CPU restent au **modèle natif** (`route`, `drave-core`) et aux mesures **boîte blanche** (perplexité, activations, flux, sondes). Une API ne donne ni les poids ni les activations : elle ne remplace pas ces mesures.
>
> **Ce que c'est, en clair.** Définition complète dans la famille.
