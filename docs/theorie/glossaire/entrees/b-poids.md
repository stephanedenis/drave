# b/poids (bits par poids)

> **Fiche glossaire — b/poids (bits par poids).** Nombre moyen de bits nécessaires pour stocker un poids. Un modèle 8 bits coûte 8 b/poids ; le format « liste d'événements » du dépôt en coûte 1,98, et un encodage ternaire 0,39 (`reports/rapport-optimisations.md:37`, `reports/rapport-valeur-unaire.md:89`).
