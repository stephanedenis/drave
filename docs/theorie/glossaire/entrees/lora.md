# LoRA (Low-Rank Adaptation ; adaptation à rang faible)

> **Fiche glossaire — LoRA (Low-Rank Adaptation ; adaptation à rang faible).** Remplacer une grosse matrice par le produit de deux petites matrices (une « descente » puis une « remontée »), ce qui réduit le nombre de paramètres. C'est le principe des projections de MLA et de la sortie groupée de V4 (`q_lora_rank`, `kv_lora_rank`, `o_lora_rank` ; `docs/plan-mla-vision.md:26-53`, `docs/plan-deepseek41-complet.md:78-88`).
