# Gist

> **Fiche glossaire — Gist.** Le **gist** est l'état résumé d'un document (thème, entités, faits) qui tient lieu de mémoire de travail entre les sections. La **mémoire épisodique** est le store des régions et de leur état, qui permet de revenir sur un passage.
