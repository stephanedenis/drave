# Constante de temps

> **Fiche glossaire — Constante de temps.** Le nombre `a` qui règle la vitesse d'oubli : `s_t = (1-a)·s_{t-1} + a·tanh(...)`. Un `a` petit garde longtemps la trace du passé, un `a` grand l'oublie vite.
