# Fiche de résultat

> **TL;DR — Fiche de résultat.** Le **document court** qui accompagne un manifeste : ce que c'est, le chiffre, le dispositif, le **contrôle négatif**, ce qui pourrait être faux, la suite. Une livraison sans fiche n'est pas une livraison.
>
> **Ce que c'est, en clair.** Définition complète dans la famille.
