# Bande passante (bandwidth)

> **Fiche glossaire — Bande passante (bandwidth).** Débit maximal d'un chemin de données : RAM (~20-25 Go/s), VRAM (~380-750 Go/s), DDR3 du FPGA (9,66 Go/s), PCIe x8 (6,5 Go/s), NVMe (3,5 à 31 Go/s selon la parallélisation).
