# Graphe de document

> **Fiche glossaire — Graphe de document.** Représentation d'un document en **régions typées** (titre, section, paragraphe, tableau, code, maths, figure), avec leur **offset** dans le fichier, leur parent et leur **provenance**. Le **manifeste** est l'objet sérialisé qui porte ces régions et survit au rejeu.
