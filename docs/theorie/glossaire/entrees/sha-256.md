# SHA-256

> **Fiche glossaire — SHA-256.** Empreinte cryptographique utilisée pour vérifier qu'un fichier converti contient bien les mêmes octets que la source, tenseur par tenseur (1 587 tenseurs vérifiés sur Qwen3-30B) (`docs/implantation/format-clusters.md:60-63`). **Réf.** : FIPS 180-4, [NIST.FIPS.180-4.pdf](https://nvlpubs.nist.gov/nistpubs/FIPS/NIST.FIPS.180-4.pdf).
