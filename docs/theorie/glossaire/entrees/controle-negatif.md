# Contrôle négatif

> **TL;DR — Contrôle négatif.** Dispositif qui doit **échouer** si la mesure ne mesure pas ce qu'elle prétend : closed-book, régions aléatoires, sections mélangées, plancher chrF. Sans lui, un chiffre n'est pas un résultat.
