# Harnais (harness)

> **Fiche glossaire — Harnais (harness).** Petit montage de test autonome, souvent en Python, qui enveloppe un composant pour le mesurer ou le comparer à une référence. Exemples : harnais de perplexité (`src/bpe_np.py`, `src/transformer_np.py`), harnais MLA (`tools/mla_synthetique.py`, `--banc-mla`), harnais de vision (`tools/vision_ref.py`).
