# PTQ (Post-Training Quantization ; quantification après entraînement)

> **Fiche glossaire — PTQ (Post-Training Quantization ; quantification après entraînement).** Réduire la précision d'un modèle **déjà entraîné**, sans réentraînement. Tout le projet est en PTQ — c'est précisément la limite qu'il mesure : la parcimonie ne s'impose pas, elle s'entraîne (`reports/bilan-multi-materiel.md:86`, `docs/programme-recherche.md:89-93`).
