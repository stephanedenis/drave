# Manifeste

> **Fiche glossaire — Manifeste.** Le **JSON de résultats** d'une extraction : source, méthode, filtres, déduplication, split, compteurs, octets, empreintes, limites. C'est la pièce qui rend un corpus **reproductible** ; il vit dans `reports/` et il est committé, contrairement aux données.
