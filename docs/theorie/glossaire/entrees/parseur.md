# Parseur

> **TL;DR — Parseur.** Programme qui transforme un format (HTML, PDF, DOCX, code, LaTeX) en structure (arbre, grille, AST). Dans R0.1, un parseur par format émet des **régions** ; il est classique, pas neuronal.
