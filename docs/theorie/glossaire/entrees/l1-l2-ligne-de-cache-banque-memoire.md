# L1 · L2 · ligne de cache · banque mémoire

> **Fiche glossaire — L1 · L2 · ligne de cache · banque mémoire.** Mémoires internes du processeur, du plus rapide (L1, quelques dizaines de Kio) au plus grand (L2 partagé, 256 Kio ici). L'accumulateur du mode push doit tenir en L1 sous peine de s'effondrer ; les banques mémoire imposent un rembourrage des tuiles transposées, sans quoi 32 voies d'une lecture tombent dans la même banque (`reports/bilan-multi-materiel.md:132`, `docs/implantation/contexte-long.md:219-224`).
