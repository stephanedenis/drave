# Impulsion

> **TL;DR — Impulsion.** Dans un réseau de neurones à impulsions, un signal bref émis quand le potentiel d'un neurone franchit un **seuil**, suivi d'une **remise à zéro**. C'est un événement, pas une valeur continue : c'est ce qui rend un tel réseau **parcimonieux par construction**.
