# int4 · int8

> **Fiche glossaire — int4 · int8.** Précisions entières : 16 niveaux signés pour int4 (ou des nibbles empaquetés), 256 pour int8. Le vocabulaire du dépôt les distingue de `i4`/`i8` (types de stockage) et de `Q4_0`/`Q8_0` (formats ggml à échelle par bloc).
