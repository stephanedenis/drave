# Quantification

> **Fiche glossaire — Quantification.** Stocker les poids (ou les activations, ou le cache) dans un format plus compact que le flottant 32 bits, au prix d'une erreur. Les deux questions du dépôt sont : *combien de bits* et *où sont les échelles* ; la seconde compte plus que la première (`docs/theorie/vision.md:198-227`).
