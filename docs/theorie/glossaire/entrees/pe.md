# PE (Processing Element ; élément de calcul)

> **Fiche glossaire — PE (Processing Element ; élément de calcul).** L'unité qui traite un événement par cycle dans le FPGA. Le dépôt en dimensionne le nombre selon la DDR3 : 51 voies tiennent la carte, l'optimum du banc seul est 32 PE à 177 MHz (`reports/bilan-multi-materiel.md:55`, `reports/rapport-cpu-aer.md:11`).
