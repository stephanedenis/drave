# Tokeniser · tokenizer

> **Fiche glossaire — Tokeniser · tokenizer.** Découper le texte en jetons et l'inverse ; le *tokenizer* est la table (vocabulaire + règles) qui fait cette conversion. Le moteur vérifie l'aller-retour texte → jetons → texte et refuse un identifiant hors vocabulaire (`docs/plan-deepseek-v4-flash.md:38`, `docs/implantation/convertisseur.md:276-281`).
