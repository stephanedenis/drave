# Professeur / élève

> **TL;DR — Professeur / élève.** Le **professeur** est le modèle externe (DeepSeek) dont on collecte les sorties ; l'**élève** est le modèle natif `route`. La **distillation** est au niveau des **séquences** (l'API ne donne pas les logits) ; le contrôle mélange les réponses d'entraînement et garde la validation alignée.
