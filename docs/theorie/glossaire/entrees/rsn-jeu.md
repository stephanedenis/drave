# RSN-jeu

> **Fiche glossaire — RSN-jeu.** La **représentation sémantique neutre** appliquée à un jeu symbolique : un **jeu** (`morpion`, `echecs`, `dames`, `go`, `cartes`), une **nature** (`etat`, `coup`, `partie`, `main`, `resultat`), un **corps** canonique (les unités de sens du jeu : cases, trait, roques, chemin, point, carte…) et une **annotation** (langue, format, confiance, ambiguïtés, surface d'origine, niveau de lecture).
