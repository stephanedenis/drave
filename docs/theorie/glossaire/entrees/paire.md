# Paire (indice, valeur) · paire (destination, valeur)

> **Fiche glossaire — Paire (indice, valeur) · paire (destination, valeur).** L'unité de contenu d'une liste : un indice (le neurone ou la destination) et une valeur quantifiée. Le mode 2 du protocole compte `n` **paires** ; le mode 4 compte des **états**, et le nombre d'actifs d'un lot est `Σ a_j` (`docs/implantation/format-flux.md:110-116`, `docs/plan-mode4-lot-listes.md:393-396`).
