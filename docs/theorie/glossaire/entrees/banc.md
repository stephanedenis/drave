# Banc (bench)

> **Fiche glossaire — Banc (bench).** Dispositif de mesure isolé qui fait tourner une seule partie du moteur sur des données choisies, pour que la bonne réponse soit connue d'avance. Le dépôt en a plusieurs : `--banc-kv`, `--banc-mla`, `--banc-topk`, `--banc-vision`, `--gpu-banc` (`drave-core/src/main.rs`).
