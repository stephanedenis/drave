# Modes 0 à 4

> **Fiche glossaire — Modes 0 à 4.** Les cinq modes du protocole v5 : **0** dense f32, **1** liste quantifiée (i16 + une échelle), **2** listes à échelle par bloc (i8, écarts), **3** lot dense, **4** lot en listes. Le mode 1 est « le format du disque, à l'octet près » ; le mode 0 est le seul sans perte avec le mode 3 (`docs/implantation/format-flux.md:93-116`).
