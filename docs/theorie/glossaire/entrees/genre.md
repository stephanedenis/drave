# Genre

> **Fiche glossaire — Genre.** La **famille de texte** que le corpus représente : encyclopédie, livre, document administratif, notes de cours. Le dépôt la mesure par des indices simples — longueur moyenne de ligne, part de lignes dupliquées, couverture lexicale — avec `tools/compare_genres.py` ; c'est ce qui distingue une encyclopédie (103-147 car/ligne) d'un livre (32-38).
