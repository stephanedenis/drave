# BLAKE2b

> **Fiche glossaire — BLAKE2b.** Une **fonction de hachage** cryptographique rapide, utilisée dans le dépôt pour **dédupliquer** : deux articles ou deux tronçons de texte identiques ont la même empreinte, et le second est écarté. Elle sert aussi à **répartir** les documents entre train/val/test (hash salé du chemin ou du `page_id`).
