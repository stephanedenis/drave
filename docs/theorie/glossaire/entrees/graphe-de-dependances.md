# Graphe de dépendances

> **TL;DR — Graphe de dépendances.** Représentation des dépendances entre fiches : une **arête dure** bloque l'artefact d'entrée ; un **plafond** borne le résultat sans bloquer le travail ; la **frontière** est l'ensemble des items disponibles. À ne pas confondre avec le plafond de flux ni avec la frontière fidélité/contenu.
>
