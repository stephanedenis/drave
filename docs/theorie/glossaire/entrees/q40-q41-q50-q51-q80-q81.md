# Q40 · Q41 · Q50 · Q51 · Q80 · Q81

> **Fiche glossaire — Q40 · Q41 · Q50 · Q51 · Q80 · Q81.** Types ggml « legacy » à blocs de 32 poids et échelle (parfois minimum) sur 16 bits. `Q8_0` est le format de référence du projet (tête de sortie, projections) ; `Q8_1` est le format des **activations** chez ggml.
