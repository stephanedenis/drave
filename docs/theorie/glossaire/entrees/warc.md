# WARC

> **Fiche glossaire — WARC.** Le **format d'archive** du Web (ISO 28500) : un fichier qui enregistre des réponses HTTP brutes (en-têtes + corps), utilisé par les robots d'archivage pour conserver des pages telles qu'elles ont été servies. Le dépôt n'en produit pas encore : le corpus web s'appuie sur les dumps Wikipédia ; le WARC est le format à connaître le jour où l'on…
