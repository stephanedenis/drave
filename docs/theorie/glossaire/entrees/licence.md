# Licence

> **Fiche glossaire — Licence.** Le **régime de droits** d'un corpus : CC-BY-SA 4.0 pour Wikipédia, « droits réservés, usage local, non diffusé » pour les livres et les notes de cours, « personnel » pour les documents. Elle est écrite dans le manifeste et dans la fiche ; un corpus sans licence nommée n'entre pas dans `reports/`.
