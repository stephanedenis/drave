# RAM · VRAM · RSS

> **Fiche glossaire — RAM · VRAM · RSS.** *RAM* : mémoire de l'hôte (125 Go ici) ; *VRAM* : mémoire des cartes graphiques (2 × 16 Go, 30,2 Go exploitables) ; *RSS* (resident set size) : mémoire réellement occupée par un processus. Le contraste qui résume le projet : **47 Mo de RSS pour 365,7 Go de modèle adressé** en `mmap` (`reports/rapport-architecture-memoire.md:370-376`).
