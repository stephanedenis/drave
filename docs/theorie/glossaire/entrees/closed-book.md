# Closed-book

> **Fiche glossaire — Closed-book.** Réglage d'évaluation où le modèle répond **sans le document**, de mémoire. C'est le contrôle négatif du banc de lecture : si le closed-book fait aussi bien que la lecture, le banc ne mesure pas la lecture.
