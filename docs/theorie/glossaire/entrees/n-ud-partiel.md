# Nœud partiel

> **Fiche glossaire — Nœud partiel.** Nœud qui ne charge qu'une partie des grappes (`DRAVE_CLUSTERS=0,3`) au lieu du modèle entier. Un cluster **demandé mais absent du disque est une erreur**, pas un silence ; et rien n'additionne encore les contributions de deux nœuds partiels (`docs/implantation/format-clusters.md:160-178`, `reports/rapport-lecteur-multifichiers.md:125`).
