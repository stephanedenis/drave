# Perplexité (PPL)

> **Fiche glossaire — Perplexité (PPL).** Exponentielle de la perte moyenne par jeton : mesure d'« étonnement » du modèle sur un texte. Plus elle est basse, mieux le modèle prédit ; un écart de quelques centièmes de pour cent est significatif sur un même corpus, mais **deux perplexités sur deux corpus ne se comparent pas** (`docs/implantation/format-flux.md:181-183`, `docs/implantation/contexte-long.md:316-319`).
