# DRVF (Drave Flux)

> **TL;DR — DRVF (Drave Flux).** Le format binaire du dépôt, à quatre usages : trace d'exécution, rejeu, transport réseau, analyse. Un fichier commence par la magie `DRVF` et une version (1, 2 ou 3) ; le transport utilise la même famille d'encodage, en protocole v5 (`docs/implantation/format-flux.md:1-24`, `docs/plan-deepseek41-complet.md:17`).
