# Puits d'attention (attention sinks)

> **Fiche glossaire — Puits d'attention (attention sinks).** Clé virtuelle de valeur nulle, apprise, qui ne compte que dans le dénominateur du softmax : elle sert de « poubelle » où le modèle jette son attention. Les oublier fausse toute la distribution, pas seulement la queue (`docs/implantation/convertisseur.md:286-288`, `docs/plan-gpu-topk.md:107-109`).
