# Régression ridge

> **TL;DR — Régression ridge.** Des moindres carrés auxquels on ajoute une pénalité proportionnelle au carré des coefficients. Elle sert à stabiliser le calcul quand les colonnes sont corrélées, ce qui est toujours le cas ici.
