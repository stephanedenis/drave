# A8.3 — Passer la règle place+perte par défaut

> **Statut** : mesurée · **Priorité** : P3 · **Programme** : A · **Dépend de** : A8.0
> **Ligne de roadmap** : A8.3 · **Fiches de résultat** :
> [`a83-defaut`](../../../reports/rapport-a83-defaut.md) et
> [`a83b-regimes`](../../../reports/rapport-a83b-regimes.md).
> **Résumé** : décider si `DRAVE_PERTE_MAX` devient le défaut ; la mesure dit **non**, pas
> encore.

## Le besoin

La règle choisit la précision du KV par couche selon la perte mesurée. Elle payait (+0,03 %
sur les dernières couches) et rendait le choix de la main. La passer par défaut ferait
bénéficier tout le monde de l'int8 tardif — à condition de ne pas déplacer les chiffres.

## L'état

**Mesurée négative** — le défaut déplace les portes épinglées de **−5,9 % à +19,5 %** ; trois
régimes sont reproductibles (f32, mélange tardif 1 %, int8 partout), et le **mélange** est un
troisième point : il **améliore deux mesures sur trois** et dégrade le mode de lot. La cause du
signe (le lot) n'est pas isolée. **A8.3 reste opt-in.**

## Le contrat

| élément | contenu |
|---|---|
| **entrée** | un budget de perte en %, la profondeur du modèle |
| **sortie** | une précision de KV par couche (f32 ou int8) |
| **coût** | nul : une décision, pas un calcul |
| **trace** | la règle imprime les couches choisies et leur nombre |

## Portes

1. le défaut ne déplace **aucune** porte épinglée au-delà de sa tolérance ;
2. le régime par défaut est **reproductible** (deux exécutions, même chiffre) ;
3. le signe de l'effet est **expliqué** (aujourd'hui : non).

## Contrôles négatifs

- budget quasi nul → le régime f32, au chiffre près ;
- budget 10 % → identique à `DRAVE_KV_BITS=8` (le chemin explicite) ;
- mode de lot contre mode dense : l'effet doit être attribuable.

## Ce qui pourrait le rendre faux

- deux portes et un modèle seulement ;
- la PPL déplacée n'est pas une qualité ;
- le mode de lot n'est pas isolé.

## Prochain

**A8.3c — fait** : le lot n'est pas neutre (**1,90 %** à lui seul) et l'effet du KV est
**cohérent par chemin** (−5,9 % jeton par jeton, +3,2 % par lots). Prochain : réduire la
non-équivalence du lot, ou passer la règle par défaut **avec des références par chemin**
(A8.3a les a épinglées).
