# A8.0 — Épingler les portes qui mesurent une PPL

> **Statut** : mesurée · **Priorité** : P2 · **Programme** : A · **Dépend de** : A8
> **Ligne de roadmap** : A8.0 · **Fiches de résultat** :
> [`a80-flux`](../../../reports/rapport-a80-porte-flux.md),
> [`a80-pont`](../../../reports/rapport-a80-porte-pont.md),
> [`a80-topologie`](../../../reports/rapport-a80-porte-topologie.md).
> **Résumé** : une porte qui mesure une PPL doit avoir une **référence chiffrée** avant qu'on
> touche à un défaut — sinon on ne sait pas ce qu'on casse.

## Le besoin

A8.3 (« opt-in → défaut ») exigeait d'épingler les portes qui mesurent une PPL. Cette
condition n'avait ni identifiant ni fiche : un changement de défaut déplaçait des chiffres
sans qu'aucune porte ne le dise. A8.0 est cette condition, nommée.

## L'état

**Mesurée** — **3 portes épinglées** :

| porte | référence épinglée |
|---|---|
| [`porte-flux`](../../../tools/porte-flux.sh) | **61,9920 / 60,8135** (modes dense et lot) |
| [`porte-pont`](../../../tools/porte-pont.sh) | **113,0068 / 111,9225** ; falaise **+2,81 % / +25,35 %** |
| [`porte-topologie`](../../../tools/porte-topologie.sh) | **17,4702 / 30,4363 / 42,5477** |

**Ce qu'elle a immédiatement attrapé** : A8.3, le passage de `DRAVE_PERTE_MAX` par défaut,
déplace ces références de **−5,9 % à +19,5 %** ([fiche](../../../reports/rapport-a83-defaut.md)).
La condition n'était pas une formalité : elle bloque un défaut qui aurait changé les chiffres
du moteur en silence.

## Le contrat

| élément | contenu |
|---|---|
| **entrée** | une porte qui calcule une PPL, et son chiffre mesuré |
| **sortie** | une référence chiffrée dans la porte, vérifiée à chaque passe |
| **coût** | le temps de la porte (20 s à 75 s) |
| **trace** | la porte échoue en nommant le chiffre attendu et le chiffre lu |

## Ce qui pourrait le rendre faux

- une référence épinglée sur **un** modèle et **une** machine ne dit rien des autres ;
- une porte épinglée peut devenir rouge pour une raison légitime (changement voulu) : il faut
  alors **réépingler** explicitement, pas tolérer ;
- les trois portes ne couvrent pas toutes les PPL du dépôt (coupe, gain, etc.).

## Prochain

expliquer la non-monotonie avant de choisir un défaut.
