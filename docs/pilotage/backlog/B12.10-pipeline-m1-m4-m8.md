# B12.10 — Pipeline M1 → M4 → M8

> **Statut** : mesurée · **Priorité** : P2 · **Programme** : B · **Dépend de** : B12
> **Ligne de roadmap** : B12.10 · **Fiche de résultat** : [rapport-cerveau-corrections.md](../../../reports/rapport-cerveau-corrections.md) § 11bis — split, oracle et marge
> **Résumé** : Mesurer l'intégration M1 → M4 → M8 sans tautologie.
> **Glossaire** : [RSN](../../theorie/glossaire/entrees/representation-semantique-neutre.md) · [RSN-jeu](../../theorie/glossaire/entrees/rsn-jeu.md).

## Le besoin

Le pipeline rend 528/528 et 96,33 % de complétion, mais M4 ne généralise pas et M8 est la marginale. Le chiffre est tautologique : il faut une mesure qui ne contienne pas la réponse.

## L'état

M1 solide (528/528) ; M2 vu seulement ; M3/M4 structurels ; M5/M6/M7 négatifs ; M8 marginal ; M9 table. **Le 29/10, la plomberie du contexte est réparée** : `ItemType.contexte` était une chaîne, le codec attendait un RSN ; le pipeline stockait 0/528. Après `contexte_rsn` et `percevoir_item`, il lit **528/528**. Le **split par code tenu à l'écart** (3 graines × 6 codes) donne **0 code exact** et **0,436** de champ, avec une variance 0,056–0,859 ; **M4 retiré ne change rien** (0,436), car `repondre` ne l'appelle pas pour un cue partiel. Un branchement par **champs observés** a été tenté : **0 sélection M4** (les champs observés sont à égalité) ; la règle est retirée, branche inerte. **Oracle et marge** : sur **606 observations**, **M4 seul = 0**, **M8 seul = 63**, oracle = **M8** (**0,436**) ; la marge ne vaut que **0** ou **0,067**, et sélectionner M4 dès qu'elle est > 0 fait tomber le champ à **0,037 / 0,028**.

## La porte

**Non franchie — et vide.** Sur un code neuf, M4 n'apporte **aucun** champ correct unique (**0/606**) ; l'oracle est M8 (**0,436**). La porte « M4 retiré ⇒ chute » ne peut pas être mesurée sur ce corpus : M4 est un **lookup exact**, pas un complémenteur.

## Contrôles négatifs

- code neuf ; retrait de M4 ; cibles mélangées
- même budget

## Prochaine action

**Aucune — close négative.** La section « 11bis » de [`rapport-cerveau-corrections.md`](../../../reports/rapport-cerveau-corrections.md) documente le correctif, le split, l'oracle et la marge. Toute suite (autre espace de code, corpus plus grand) est **hors plan**.
