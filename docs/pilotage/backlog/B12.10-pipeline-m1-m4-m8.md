> **Résumé** : Mesurer l'intégration M1 → M4 → M8 sans tautologie.
> **Glossaire** : [RSN](../../theorie/glossaire/entrees/representation-semantique-neutre.md) · [RSN-jeu](../../theorie/glossaire/entrees/rsn-jeu.md).

## Le besoin

Le pipeline rend 528/528 et 96,33 % de complétion, mais M4 ne généralise pas et M8 est la marginale. Le chiffre est tautologique : il faut une mesure qui ne contienne pas la réponse.

## L'état

M1 solide (528/528) ; M2 vu seulement ; M3/M4 structurels ; M5/M6/M7 négatifs ; M8 marginal ; M9 table. **Le 29/10, la plomberie du contexte est réparée** : `ItemType.contexte` était une chaîne, le codec attendait un RSN ; le pipeline stockait 0/528. Après `contexte_rsn` et `percevoir_item`, il lit **528/528**. Le **split par code tenu à l'écart** (3 graines × 6 codes) donne **0 code exact** et **0,436** de champ, avec une variance 0,056–0,859 ; **M4 retiré ne change rien** (0,436), car `repondre` ne l'appelle pas pour un cue partiel. Un branchement par **champs observés** a été tenté : **0 sélection M4** (les champs observés sont à égalité) ; la règle est retirée, branche inerte.

## La porte

Une complétion sur un code neuf, avec un contrôle où M4 est retiré ; le score doit chuter.

## Contrôles négatifs

- code neuf ; retrait de M4 ; cibles mélangées
- même budget

## Prochaine action

Essayer la **marge de similarité** (top1 − top2) ou changer la porte ; le branchement par champs observés est inerte. Écrire la fiche. La section « 11bis » de [`rapport-cerveau-corrections.md`](../../../reports/rapport-cerveau-corrections.md) documente le correctif et le split.
