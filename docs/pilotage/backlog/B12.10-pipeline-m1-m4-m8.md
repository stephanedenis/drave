> **Glossaire** : [RSN](../../theorie/glossaire/entrees/representation-semantique-neutre.md) · [RSN-jeu](../../theorie/glossaire/entrees/rsn-jeu.md).

## Le besoin

Le pipeline rend 528/528 et 96,33 % de complétion, mais M4 ne généralise pas et M8 est la marginale. Le chiffre est tautologique : il faut une mesure qui ne contienne pas la réponse.

## L'état

M1 solide (528/528) ; M2 vu seulement ; M3/M4 structurels ; M5/M6/M7 négatifs ; M8 marginal ; M9 table. **Le 29/10, la plomberie du contexte est réparée** : `ItemType.contexte` était une chaîne, le codec attendait un RSN ; le pipeline stockait 0/528. Après `contexte_rsn` et `percevoir_item`, il lit **528/528**. La généralisation M4/M8 reste à mesurer.

## La porte

Une complétion sur un code neuf, avec un contrôle où M4 est retiré ; le score doit chuter.

## Contrôles négatifs

- code neuf ; retrait de M4 ; cibles mélangées
- même budget

## Prochaine action

Construire un split par **code tenu à l'écart**, mesurer la complétion M4/M8 avec **M4 retiré** ; écrire la fiche. La section « 11bis » de [`rapport-cerveau-corrections.md`](../../../reports/rapport-cerveau-corrections.md) documente le correctif.
